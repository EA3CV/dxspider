`git://scm.dxspider.org/spider`

`https://github.com/EA3CV/dxspider`

## What is DXSpider?

**DXSpider** is software designed for creating and operating **DX Cluster** nodes within the amateur radio service.

A DX Cluster allows amateur radio operators to exchange real-time information about DX stations, propagation, activity on the different amateur radio bands, and other information relevant to radio operation.

DXSpider provides the infrastructure required for a node to receive, process, and distribute this information among users and other nodes on the network.

It is primarily written in **Perl** and designed to run on Unix/Linux systems.

## Why was DXSpider developed?

DXSpider was developed as a modern and flexible platform for operating DX Cluster networks, allowing nodes and users to be interconnected and DX information to be distributed efficiently.

The project has evolved over many years to adapt to the needs of the international amateur radio community and to the evolution of DX Cluster networks themselves.

Its functions include managing user and node connections, distributing DX spots, announcements and messages, filtering information, and maintaining connectivity between the different nodes in the network.

Over the years, DXSpider has become the most widely used system for operating DX Cluster nodes.
